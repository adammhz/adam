# SmartGear AI - Group 7 Project

## Project Overview
A software-driven storage and tracking system for community sports equipment hubs.

## How to Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Initialize database: `python backend/database.py`
3. Start server: `cd backend` then `uvicorn main:app --reload`
4. Open `frontend/index.html` in a web browser.
